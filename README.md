# PACS 통계 프로그램 — 집계 및 엑셀 출력 초안

현재 구현: 검사실별 집계, 한국 시간 기준 오늘/지정일 분류, 2시간대별 exam/image 계산, Chest DX+PR의 Series count 2·3·4에 대한 1·2·3장 차감, 원본 엑셀 서식 유지 출력. SRS 표에는 차감 대상 검사 건수를 image 칸에 입력하고 exam은 비워 둡니다.

추가된 기능: Windows 실행 화면, PACS UI Automation 구조 진단, 검사실 5곳의 가상 통계 생성. 아직 구현되지 않은 기능: 실제 PACS 검사 행 수집, 스크롤/페이지 이동, OCR, 실시간 통계 시작 기능. 병원 PC에서의 실제 수집 및 업무 통계 대조도 미검증입니다. 이 초안의 JSON 입력은 화면 수집기가 나중에 전달할 내부 데이터 형식이며, PACS에서 파일을 내보내야 한다는 뜻이 아닙니다.

## 다른 PC에서 사용

1. 이 저장소를 내려받고 ZIP이라면 압축을 풉니다.
2. 병원 Windows PC에 Python 3.12를 설치합니다. 프로그램 실행 및 패키지 설치가 허용된 PC에서 진행합니다.
3. `start_windows.bat`를 더블클릭합니다. 최초 실행은 패키지 다운로드를 위해 인터넷이 필요합니다.
4. **가상 통계 엑셀 만들기**를 누르고 저장 폴더를 고릅니다. 해당 PC에 가상 샘플 5개를 직접 생성하므로 Codex 다운로드 링크가 필요하지 않습니다.
5. PACS 검사 목록 화면을 열고 **PACS 창 찾기 → 화면 구조 진단**을 실행합니다. PACS 후보가 여러 개면 창 핸들로 구분해 선택합니다.

진단 JSON에는 제어 요소 개수와 알려진 열 제목만 들어갑니다. 환자 이름·번호·검사 행·스크린샷은 저장하지 않습니다. 표 요소가 보인다고 전체 수집이 가능한 것은 아니며, 0개이면 다른 접근 방식이나 OCR이 필요할 수 있습니다. Windows 진단과 실행 화면은 클라우드 Linux 환경에서 실제 PACS와 검증할 수 없습니다.

샘플은 2026년 10월 7일 가상 검사로 각 검사실 exam 3건, 보정 image 5장입니다. 실제 오늘 통계가 아닙니다. 자동 수집을 연결한 후 실제 통계 날짜는 한국 현지 날짜로 결정합니다.

`templates/statistics_blank.xlsx`는 제공 양식에서 기존 집계값을 비운 템플릿입니다. 원본 업로드 파일과 실제 병원 통계는 포함하지 않습니다. 이 단계는 Python 실행 방식이며 설치 없는 독립 `.exe` 배포는 아직 준비하지 않았습니다.

## 실행

Python 3.12 및 `pip install -r requirements.txt`로 준비합니다.

```sh
python pacs_statistics.py --template '양식.xlsx' --records normalized.json --aetitle ER_DR --output '오늘통계.xlsx'
```

날짜 기본값은 실행 시점 한국 날짜입니다. `--date 2026-10-07`로 지정할 수 있습니다. 같은 월·AE Title의 기존 생성 파일을 `--previous 이전통계.xlsx`로 지정하면 해당 날짜 값만 교체하고 다른 날짜 값은 유지합니다. 원본 및 이전 파일은 덮어쓰지 않으며 출력 경로는 새 파일이어야 합니다. 기존 파일을 지정하지 않는 첫 출력은 양식의 예시 통계를 비우고 시작합니다.

현재는 제공 양식에 AI 제거 시트가 있는 2026년 3~10월을 지원합니다. 다른 월은 템플릿 확장이 필요합니다. 출력은 선택 AE Title의 월별 시트 한 개와 기존 원본/SRS 보조 표를 포함합니다. 합계와 최종 값은 프로그램이 계산해 저장하므로 엑셀 재계산 없이도 읽을 수 있습니다.

각 레코드에는 `study_id`, ISO 형식 `study_datetime`, `source_aetitle`, `modality`, 정수 `series_count`, 정수 `instance_count`, 불리언 `is_chest`가 필요합니다. 시간대가 없는 시각은 병원 한국 현지 시각으로 해석합니다. 안정적인 검사 식별자와 Chest 분류를 화면 수집기에서 제공할 수 있는지는 실제 PC에서 확인해야 합니다.

중복 검사 식별자, 지원하지 않는 Chest AI Series count, 잘못된 장수는 오류로 처리합니다. 화면 수집의 전체성은 이 계산 모듈만으로 검증할 수 없습니다. 0건 출력은 수집 누락일 수 있으므로 향후 화면 수집기가 별도로 확인해야 합니다. Series count 차감 규칙은 제공 양식에 따른 업무 규칙이며 실제 PR 장수와 대조가 필요합니다.

## 검증

```sh
python -m unittest -v
```

테스트는 저장소의 빈 템플릿을 사용하므로 다른 PC에서도 같은 경로 수정 없이 실행할 수 있습니다. 생성된 샘플은 가상 검사 데이터만 포함합니다. 터미널에서는 `python demo.py --output-dir output/demo`로 샘플을 생성할 수 있습니다.
